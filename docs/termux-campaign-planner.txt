التركيب:
1. أوقف الباكإند والواجهة في تيرمكس بـCtrl+C لكل واحد.
2. نزّل marketflow-campaign-planner-update.pyz في Download، ثم نفّذ:

python /sdcard/Download/marketflow-campaign-planner-update.pyz

الأداة تطبّق التحديث على فرع updates/campaign-planner-v1 وترفعه بدون force. تحافظ على .env والبيانات، وتتوقف عند وجود تعديلات متتبعة غير محفوظة أو عملية Git لم تنتهِ. عند تشغيل الباكإند تضاف خانة للخطة داخل جدول الحملات؛ الحملات القديمة تظل موجودة. لا توجد مكتبات جديدة لهذا التحديث.

3. بعد نجاح الرفع، افتح:
https://github.com/ahmedmsaad1347-ops/marketflow-app/compare/main...updates/campaign-planner-v1?expand=1

Create pull request → Merge pull request → Confirm merge.

ثم في جلسة الأوامر:

cd ~/marketflow-app &&
git switch main &&
git pull --ff-only origin main

4. شغّل الباكإند:

cd ~/marketflow-app &&
source .venv/bin/activate &&
python -m uvicorn backend.main:app --host 127.0.0.1 --port 3000

وفي جلسة أخرى، شغّل الواجهة:

cd ~/marketflow-app &&
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort --force

افتح http://localhost:5173/app وحدّث الصفحة، ثم Campaigns → New Campaign.

مثال تجريبي، وليس عرضًا عقاريًا حقيقيًا أو تسعيرة لسوق الإعلانات:
الخطوة الأولى:
Campaign name: معاينات الشروق
Product: شقة 140 مترًا في الشروق، 3 غرف و2 حمام
Audience: الباحثون عن شقة للسكن في الشروق
Country: Egypt
Goal: Leads
Platform: Facebook

الخطوة الثانية:
Brand: سكنك للعقارات
Currency: EGP
Duration: 14 days
Destination: Phone call
Target qualified leads: 20
Known / assumed cost per qualified lead: 50
Maximum affordable test spend: 600
Language: العربية · مصري
Benefit: فصل الاستقبال عن غرف النوم
Offer: السعر 2,400,000 جنيه. مقدم 600,000 جنيه والباقي على 5 سنوات.

رقم 50 افتراض لتجربة الحساب، وليس متوسط تكلفة إعلانات العقارات. الحساب: 20 × 50 = 1000 جنيه كميزانية سيناريو. مع سقف 600 يختار 600 جنيه، ومتوسط 42.86 يوميًا، ويعرض فرق تمويل 400. لا يَعِد بتحقيق 20 عميلًا محتملًا بهذا السقف.

اضغط Suggest my budget & ad idea، ثم Use this budget & ad idea. بعدها Review your plan → Save Campaign. جرّب تحديث الصفحة والتعديل والبحث والنسخ والأرشفة. إذا غيّرت الميزانية يدويًا، تظل محفوظة ويظهر التقدير السابق كمرجع.

لو ليس لديك تكلفة نتيجة معروفة:
افتح قسم Business economics وأدخل إيرادك/عمولتك من الصفقة وهامش الربح والتكلفة الإضافية ونسبة إغلاق العملاء المحتملين. ستستخدم المنصة 70% من المساهمة بعد التكاليف كقاعدة تخطيط، مع نسبة الإغلاق. في العقارات استخدم عمولتك/إيرادك الفعلي، لا سعر الوحدة كلها إذا كنت وسيطًا.

الاقتراح سيناريو محسوب وليس سعر مزاد مضمونًا. من غير بيانات كافية ستطلب المنصة المدخلات اللازمة بدل اختلاق ميزانية. اختر العملة ثم أدخل كل الأرقام بنفس العملة؛ لا يوجد تحويل عملات تلقائي. ميزانية الميديا لا تشمل إنتاج المحتوى أو الأتعاب أو الضرائب. شروط المنصة والحدود الفعلية تتراجع عند تجهيز التكامل.

للـStrategy: اختر Recommend a budget for me بدل إدخال Total budget. وفي الشات اختر Recommend a budget عند سؤال الميزانية.

التحقق: 119 اختبار وحدة/API، وبناء الإنتاج، واختبار متصفح للحملات والميزانية والحفظ والموبايل، واختبار رجوع محرر الاستراتيجية نجحت. لا توجد تجربة إنفاق إعلاني حقيقي أو API موديل مدفوع.

لو ظهر خطأ توقف عنده وأرسل نصه، دون كلمات مرور أو روابط تحقق. لا تستخدم reset أو force.
