تحديث MarketFlow — 17 أكتوبر 2026

يشمل: الواجهة الداخلية الجديدة، Light وDeep Blue، لوجو MarketFlow، تحليلات تفاعلية دقيقة بالعملة المختارة، واستوديو إنشاء وتعديل المحتوى وحفظ النسخ وتقييم المستخدم.
يشمل أيضًا إصلاح إعداد البريد الذي لم يُرفع سابقًا. لا يفعّل بريدًا أو حساب إعلانات أو AI بمفرده.

1) التثبيت والرفع من Termux

نزّل marketflow-workspace-update.pyz إلى Download.
شغّل:

python /sdcard/Download/marketflow-workspace-update.pyz

الأداة تستخدم ~/marketflow-app، تجلب origin/main، تنشئ/تستأنف فرع updates/workspace-creative-v1، تطبّق التحديثات الناقصة، ثم ترفع الفرع دون force.
لن تمسح تعديلات محلية متتبعة أو تتجاوز عملية Git غير مكتملة. تحافظ على .env وقاعدة البيانات والبريد المحلي المستثنى من Git.
إذا ظهر خطأ، توقف وأرسل ناتج git status فقط؛ لا تستخدم reset أو force ولا تكرر git am.
إذا الهاتف لا يرى Download، شغّل termux-setup-storage واسمح بالوصول للملفات.

2) دمج التحديث على GitHub

افتح الرابط بعد نجاح الرفع:
https://github.com/ahmedmsaad1347-ops/marketflow-app/compare/main...updates/workspace-creative-v1?expand=1

base: main
compare: updates/workspace-creative-v1
Create pull request، ثم Merge pull request / Confirm merge بعد المراجعة.
التحديث يعمل محليًا على الفرع الجديد قبل الدمج أيضًا.

بعد الدمج، إذا رغبت بالرجوع إلى main:

cd ~/marketflow-app &&
git switch main &&
git pull --ff-only origin main

3) إعادة تشغيل المنصة على الهاتف

أوقف السيرفرين القديمين بـCtrl+C في جلساتهما. لا تشغّل نسختين على نفس المنفذ.

جلسة الباكإند:

cd ~/marketflow-app &&
source .venv/bin/activate &&
python -m uvicorn backend.main:app --host 127.0.0.1 --port 3000

جلسة الواجهة:

cd ~/marketflow-app &&
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort --force

افتح Chrome وحدّث:
http://localhost:5173/app

استخدم localhost باستمرار أثناء التسجيل والتحقق؛ لا تبدله بـ127.0.0.1 في المتصفح.
لو احتجت اعتماديات Python بسبب نسخة قديمة، نفّذ داخل .venv:
python -m pip install --no-build-isolation --no-binary=pydantic -r requirements.txt

المظهر: زر الشمس/القمر أعلى الصفحة أو Settings → Appearance. الاختيار محفوظ على الجهاز.
التحليلات: Reports. اختر الفترة والمصدر والعملة، وبدّل Money / Outcomes / Traffic، وجرّب Export CSV.
الأرقام الفعلية تحتاج بيانات مستوردة من مصدر متصل. لا نضيف أمثلة مصطنعة لحسابك. Refresh يعيد قراءة النتائج المحفوظة ولا يطلق مزامنة منصة الإعلانات.

المحتوى: Creative Studio في قائمة الأدوات الجانبية؛ على الموبايل افتح زر القائمة أعلى الصفحة.
اختر اللغة، النبرة، المنصة والهدف. اكتب تفاصيل صحيحة للمنتج والعرض. اختر من 3 اتجاهات، عدّل النص وقيّمه واحفظه، ثم اطلب نسخة محسنة. النسخة القديمة محفوظة في Saved versions.
يمكن فتحه من Strategy Agent أو من قسم الكرياتيف في نتيجة الاستراتيجية لإعادة استخدام بيانات النشاط.

تفعيل كتابة المحتوى بالـAI — اختياري ويحتاج مفتاح OpenAI API خاص بك:

cd ~/marketflow-app &&
source .venv/bin/activate &&
python tools/setup_creative_ai.py

المفتاح يكتب بشكل مخفي ويُحفظ محليًا فقط في .env بصلاحية 0600، مع الحفاظ على إعدادات البريد والمنصات.
اشتراك ChatGPT منفصل عن فوترة API. الأداة تتحقق من الوصول للموديل دون توليد محتوى؛ أول توليد يختبر صلاحية التوليد والفوترة.
بعد الإعداد أعد تشغيل الباكإند. تظهر AI writing agent connected.
بدون المفتاح يعمل الاستوديو بمسودات إرشادية معنونة بوضوح، وتعديل يدوي؛ التعديلات الحرة بالوكيل تحتاج الاتصال بالـAI.
لا ترسل المفتاح أو .env في الشات أو الصور أو GitHub.

تفعيل بريد Gmail الحقيقي، إذا لم يُفعّل:

cd ~/marketflow-app &&
source .venv/bin/activate &&
python tools/setup_mail.py

استخدم App Password من Google، لا كلمة المرور العادية. أعد تشغيل الباكإند بعد الإعداد.
التحقق يستخدم أحدث رابط في نفس المتصفح، لا رمزًا رقميًا.

التسليم والتحقق:
- 87 اختبار وحدة/API، وبناء الإنتاج، واختبارات متصفح للمظهر والتحليلات والمحتوى والتسجيل وتعديل الاستراتيجية نجحت.
